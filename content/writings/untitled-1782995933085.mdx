we're in the personal software era. 

there's this underserved gap of tools and products that where the market is too small or niche for any company to pursue but painful enough that people complain and have inefficient workarounds. 

now we can make our own tools and not wait for companies to build these things for us. we have the best context of our own problems and the timelines to build a solution and solve it can be as short as an afternoon or a weekend. 

a list of personal things i've built: 

- chrome extension that unblocks netflix householder verification 
- mac desktop app that wraps around claude code / codex with an experience that mixes claude desktop, cursor, and conductor.build 
- file-based learning tool to transcribe youtube videos with workflows to write me summaries and deep-dives 
- mac desktop app with keyboard shortcut to screenshot to agentic task creation with personal kanban board 
- claude skills for writing emails, messages, proposals, content

great products will still be built by companies and will be still be valuable but it's a special time to know now you don't have to wait for another person to come up with and build the thing you want right now. 

(i'm writing this as fable 5 has returned which has only made more complex ideas easier to build)
