Cereal Code is a code editor born out of my frustration of switching between Claude Desktop and Cursor. Also heavily inspired by the UX of Cursor 3 and Conductor.build

Wraps Claude Code and Codex CLI for coding models. Works as an orchestrator of agents and surfaces sessions that are completed or need your attention to reduce context switching pain. Utilizes keyboard shortcuts and queueing to coding work more productive. 

Tech stack: 
- Electron
- Vite 
- Typescript 
- Native Wind 

Download for MacOS: [https://cereal.inflectlabs.co](https://cereal.inflectlabs.co)
